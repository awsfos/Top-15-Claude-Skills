What Are Claude Agent Skills?Claude Agent Skills are modular capability packages. They teach Claude how to follow specific multi-step workflows, process specialized file types, or execute background code without needing manual prompt instructions every time.   Instead of bloating every chat with long instructions, skills use a progressive disclosure system:   Frontmatter Scanning: Claude only reads the short name and description of installed skills when a session starts.   On-Demand Loading: When your prompt matches a skill's purpose, Claude loads the full instruction file (SKILL.md) and any attached scripts into its context.   Execution: Claude runs the workflow or executes background tools (like Python scripts, Playwright, or document parsers) to complete the task.   Key Capability Tiers1. Developer, Agent & Systems (High Leverage)MCP Builder: Guides the creation of custom Model Context Protocol servers to connect Claude directly to local databases, APIs, and execution environments.Web App Testing: Automated browser control via Playwright to navigate local web apps, inspect DOM elements, and capture bug screenshots.   Frontend Design: Enforces opinionated design systems to build custom React and Tailwind interfaces, avoiding generic default layouts.2. Precision File Handling & DataOffice Automation (xlsx, docx, pptx): Reads, writes, and formats native spreadsheets, documents, and slides using deterministic scripts to guarantee working formulas and layouts.PDF Extraction: Parses unstructured tables, key-value fields, and forms from PDF files using OCR and Python parsing tools.3. Workflow & Meta CapabilitiesSkill Creator: A built-in meta-skill that helps you scaffold, test, and write instructions for your own custom team skills.   Productivity & Strategy: Includes skills for meeting transcript summaries, customer review analysis, research briefs, and code-driven p5.js canvas graphics.
